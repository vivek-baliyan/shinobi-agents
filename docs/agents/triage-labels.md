# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-council`      | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-intel`        | Waiting on reporter for more information |
| `ready-for-agent`          | `mission-ready`      | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `hokage-review`      | Requires human implementation            |
| `wontfix`                  | `forbidden-jutsu`    | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table — e.g. `mission-ready`, not `ready-for-agent`.

Edit the right-hand column to match whatever vocabulary you actually use.
